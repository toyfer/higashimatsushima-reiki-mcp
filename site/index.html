東松島市例規 静的API

東松島市が公開している例規ページから GitHub Actions で生成した読み取り専用 JSON です。一次情報は東松島市公式サイトで確認してください。

エンドポイント

  • api/meta.json
  • api/health.json
  • api/laws/index.json
  • api/search/title-index.json
  • api/search/manifest.json
  • api/search/postings-{00..15}.json
  • api/search/chunks-{000..040}.json
  • api/laws/{law_id}.json

例

GET /api/meta.json
GET /api/laws/index.json
GET /api/laws/r122RG00000002.json
GET /api/search/manifest.json

本文検索

api/search/manifest.json はビルド時に生成した bigram TF-IDF 索引の説明です。data_version は同じビルドで作られた postings と chunks の版を表すので、検索前に必ず照合してください。版が一致しない postings と chunks を組み合わせると、chunk 番号が別の条例を指します。

検索は近似です。1 term あたり最大 50 posting、1 条例・1 term あたり最大 3 posting に削られ、Worker 側も 1 回の呼び出しで最大 40 fetch・300 候補で打ち切ります。打ち切りが起きた場合は truncated と truncation_reasons が返ります。0 件と打ち切りの区別に使ってください。

日本語は 2 文字以上のクエリが必要です（索引が bigram のみのため、税 のような 1 文字は対象外）。

版の扱い

公開しているのは現在版のみです。各条例 JSON には content_current_date と data_version が入ります。過去時点の条文は提供しないため、日付指定の取得は未対応として明示的に拒否します。

MCP は Cloudflare Worker がこの静的 API をラップして提供します。ツールは reiki_status、search_laws_by_title、search_laws_by_content、get_law、get_article、get_toc、get_unit の 7 つです。
